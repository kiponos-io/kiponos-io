# react-sdk-rate-limit

Java peer for **RPS cap** with the **@kiponos/react** SDK as the write/UI side.

## Hub key

`api/rate-limit-rps` (default `100`)

## Run

```bash
export KIPONOS_ID=… KIPONOS_ACCESS=…
export KIPONOS="['MyApp']['1.0']['Dev']['base']"
```

See `docs/examples/medium-drafts/react-sdk-rate-limit.md` and `sdks/kiponos-react-sdk`.
