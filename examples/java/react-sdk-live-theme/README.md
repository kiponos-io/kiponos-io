# react-sdk-live-theme

Java peer for **theme string on the hub** with the **@kiponos/react** SDK as the write/UI side.

## Hub key

`ui/theme` (default `dark`)

## Run

```bash
export KIPONOS_ID=… KIPONOS_ACCESS=…
export KIPONOS="['MyApp']['1.0']['Dev']['base']"
```

See `docs/examples/medium-drafts/react-sdk-live-theme.md` and `sdks/kiponos-react-sdk`.
