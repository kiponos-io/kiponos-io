# angular-sdk-incident-pause

**Pause Dangerous Angular Actions Without Killing the Session**

Multi-SDK Super Pattern peer set:
- **Java** (this directory) — `./gradlew run` / `./gradlew test`
- **Python** — `examples/python/angular-sdk-incident-pause/`
- **Node (angular)** — `examples/node/angular-sdk-incident-pause/`

## Hub leaf

`incident/pause-risky` (default `off`)

## Run (Java)

```bash
export KIPONOS_ID=… KIPONOS_ACCESS=…
export KIPONOS="['MyApp']['1.0']['Dev']['base']"
./gradlew test
./gradlew run
```
