# angular-sdk-feature-kill

Java peer for **boolean-ish kill flag** with the **@kiponos/angular** SDK as the write/UI side.

## Hub key

`flags/feature-x` (default `off`)

## Run

```bash
export KIPONOS_ID=… KIPONOS_ACCESS=…
export KIPONOS="['MyApp']['1.0']['Dev']['base']"
```

See `docs/examples/medium-drafts/angular-sdk-feature-kill.md` and `sdks/kiponos-angular-sdk`.
